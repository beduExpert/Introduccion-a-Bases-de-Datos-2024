# 🟢 RETO 1 — El precio fuera de lo común

## Contexto
La tienda quiere identificar los productos cuyo precio está por encima del precio promedio.

## Tu misión
Obtén:
* `nombre_producto`
* `precio`
* `precio_promedio`

Pero **solamente** muestra productos cuyo precio sea superior al promedio.

## Restricciones
* 🚫 No puedes escribir manualmente el promedio.
* 🚫 No puedes usar dos consultas separadas.
* ✅ Debes utilizar una subconsulta.

## Pista
Necesitas utilizar la función de agregación: `AVG()`

Y piensa: *"Necesito conocer primero el promedio para poder filtrar."*

## Bonus 🔥
Modifica la consulta para encontrar los productos que estén por debajo del promedio.
